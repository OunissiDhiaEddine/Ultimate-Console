## Install

1. Download **UltimateConsole-win-Setup.exe** below and run it. No admin
   needed; it installs for your user into `%LOCALAPPDATA%\UltimateConsole`.
   Windows SmartScreen may warn because the installer isn't code-signed:
   choose *More info → Run anyway*.
2. The settings app opens and the background agent starts (and from now on
   starts at every logon). Set up your TV display and the IRIS TV there.
3. For automatic updates, paste a GitHub fine-grained token (this repo only,
   *Contents: read-only*) on the *About / Updates* page.

Hotkeys (change them in settings): **Ctrl+Alt+G** gaming mode,
**Ctrl+Alt+O** overlay, **Ctrl+Alt+Shift+R** panic restore.

Uninstall from *Settings → Apps → Installed apps → Ultimate Console*, or the
*Uninstall* button in the settings app. It restores the desktop if needed and
deletes everything, including config, logs and the TV pairing key.
