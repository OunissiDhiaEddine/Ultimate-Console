# WP-12 · Steam Quick Access Menu tab — manual checklist (about 10 minutes)

Run on the real PC with `uc-probe.exe` and `uc-agent.exe` from the CI
artifact or `cargo build --release`. Have a controller connected and two or
three normal windows open (Notepad, a browser).

**If something fails, paste the output of `uc-probe steam-menu run` and the
last lines of `%LOCALAPPDATA%\UltimateConsole\logs\agent.*`.** The `found:`
line says which of Steam's components the script found; that's what to fix
after a Steam update.

1. **Switch file and port**
   - Quit the agent (Task Manager) so it doesn't answer at the same time.
   - `uc-probe steam-menu switch on`
   - [ ] It prints `created …\Steam\.cef-enable-remote-debugging` (or
         `already there` if Decky/Millennium made it).
   - Fully quit Steam (*Steam → Exit*) and start it again.
   - `uc-probe steam-menu targets`
   - [ ] Lists pages, including `SharedJSContext`, and ends with
         `would inject into: SharedJSContext`.

2. **The tab shows up**
   - Open Big Picture. `uc-probe steam-menu run --open`
   - [ ] `status:` goes to `Ready: …` within a few seconds of Big Picture
         opening; `found:` lists what was found.
   - [ ] The Quick Access Menu opens by itself on the **Ultimate Console**
         tab (controller icon). If not: press Steam + A (or **…**) and look
         for the icon at the bottom of the tab list.
   - [ ] The tab shows Console, Volume, Windows, Performance and Batteries.

3. **Controller and actions**
   - [ ] D-pad up/down moves through the tab like Steam's own tabs; the
         focused item is highlighted.
   - [ ] Moving the Volume slider changes the Windows volume (check the
         speaker icon on the desktop, or `uc-probe audio volume`); Mute works.
   - [ ] Per-app sliders appear for apps playing sound (play a video) and
         change only that app.
   - [ ] With two audio outputs, *Use this* switches the default output.
   - [ ] Windows: Notepad and the browser are listed (Big Picture itself is
         not). *Switch to* brings that window to the front and closes the menu;
         *Close* closes it; *End* asks *Sure?* and ends it on the second press.
   - [ ] Performance shows CPU, GPU, memory and the display mode, updating
         every second while the tab is open.
   - [ ] Batteries lists the controller with its level after a few seconds;
         *Read again* re-reads.

4. **Survives Steam**
   - [ ] Leave Big Picture and open it again: the tab is still there (the
         probe may print `status:` lines while Steam rebuilds its UI).
   - [ ] Start a Steam game, open the in-game overlay (Steam button) and the
         Quick Access Menu: the tab is there too.
   - [ ] Quit Steam: the probe says `Waiting for Steam …`; start Steam and
         Big Picture again: back to `Ready`.
   - Ctrl+C the probe.

5. **With the agent, in gaming mode**
   - Start the agent, enter gaming mode (`Ctrl+Alt+G`).
   - [ ] Settings app → Steam page → *Status:* says `Ready: …`.
   - [ ] `Ctrl+Alt+O` with Big Picture in front opens the Quick Access Menu
         on the Ultimate Console tab.
   - [ ] `Ctrl+Alt+O` with Notepad in front (switch to it from the tab)
         opens the full-screen overlay instead.
   - [ ] Console shows *Gaming mode* and the TV state; *Leave gaming mode*
         (press twice) restores the desktop, monitors and TV.
   - [ ] Keyboard volume keys still show the volume popup, and an open tab
         follows the new level.

6. **Turning it off**
   - Settings → Steam → untick *Add an Ultimate Console tab …*, Save.
   - [ ] Status says `Off`; `.cef-enable-remote-debugging` is gone from the
         Steam folder (if the agent made it). After a Steam restart
         `uc-probe steam-menu targets` fails to connect.
   - [ ] `Ctrl+Alt+O` opens the full-screen overlay again.
   - Tick it again, Save, restart Steam: the tab comes back.
   - [ ] Uninstall (later, on a test pass) removes the switch file too.
