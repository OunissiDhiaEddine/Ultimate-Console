# WP-08 manual check: the agent (about 10 minutes)

Download the `ultimate-console-<sha>` artifact from the CI run of the PR,
unzip it, and open PowerShell there. Before you start:

- The TV is set up in `%APPDATA%\UltimateConsole\config.toml` (or with the
  settings app): `[display] target` picked, `[tv] enabled = true` with `ip`
  and `mac`, and paired once (`uc-probe tv pair`, see WP-02).
- Steam is installed and signed in. Save your work: gaming mode hides the
  taskbar.

**Escape hatches at any point:** the panic hotkey `Ctrl+Alt+Shift+R`, or
Ctrl+Shift+Esc → File → Run new task → `explorer`.

Logs are in `%LOCALAPPDATA%\UltimateConsole\logs\agent.<date>.log`; keep that
file open in Notepad to watch what happens.

1. **Start.** Run `.\uc-agent.exe`. Nothing appears (it is headless). The
   log shows `uc-agent starting`, three `hotkey registered` lines and
   `IPC server listening`. Run `.\uc-agent.exe` again → the second copy
   logs `another agent is already running` and exits.
2. **Enter.** Press `Ctrl+Alt+G` → the TV wakes, the taskbar disappears
   (no sign-out), the picture moves to the TV only, Big Picture opens in
   front. Log: `gaming mode on`.
3. **Exit by hotkey.** Press `Ctrl+Alt+G` again → Big Picture closes, the
   monitor layout comes back, the taskbar returns (right-click Start works
   as usual), the TV goes to sleep. Steam stays running in desktop mode.
4. **Exit from Big Picture.** Enter again, then in Big Picture pick
   Power → Exit Big Picture → about 2 s later the desktop is restored the
   same way. Repeat with Power → Exit Steam.
5. **Sleep in gaming mode.** Enter, then sleep the PC from Big Picture
   (Power → Sleep) → the TV goes off right away. Wake the PC → within about
   15 s the TV wakes, the picture is on the TV only, Big Picture is in front.
6. **Sleep outside gaming mode (must do nothing to the TV).** In desktop
   mode, open Big Picture yourself from Steam, turn the TV on by hand, then
   sleep and wake the PC → the TV is not touched (log: `suspend: TV left
   alone`).
7. **Panic.** Enter, then press `Ctrl+Alt+Shift+R` → everything is
   restored as in step 3. Also press it once in desktop mode → nothing
   breaks (it only makes sure Explorer runs).
8. **Panic while entering.** Press `Ctrl+Alt+G` and right away
   `Ctrl+Alt+Shift+R` → entering stops and the desktop comes back.
9. **Crash recovery.** Enter, then kill the agent in Task Manager
   (Details → `uc-agent.exe` → End task). Run `.\uc-agent.exe` again → it
   logs `agent restarted during gaming mode; carrying on`, and
   `Ctrl+Alt+G` still exits normally. Now enter, kill the agent, close Big
   Picture, run the agent again → it restores the desktop on start.
10. **Config hot reload.** With the agent running, change `gaming_toggle`
    in `config.toml` to `"Ctrl+Alt+J"` and save → within 2 s the log shows
    `config.toml changed; reloading` and `Ctrl+Alt+J` now toggles. Put it
    back. Then save a broken file (e.g. `gaming_toggle = "Ctrl+Nope"`) →
    the log shows `config.toml not reloaded` and the old shortcut keeps
    working.
11. **Taken shortcut.** Start another app that uses `Ctrl+Alt+G` globally
    (if you have one) before the agent → the log reports
    `Ctrl+Alt+G is already used by another program`.
12. **Autostart.** `.\uc-agent.exe --autostart on` → `regedit`,
    `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` has
    `UltimateConsole` with the quoted path of `uc-agent.exe`.
    `.\uc-agent.exe --autostart off` removes it.
13. **Settings app link (once WP-09 is merged).** Open `uc-settings.exe` →
    the header shows the agent as running and the mode. Its Enter/Exit
    buttons, TV test buttons, hotkey checks and Identify work. "Stop agent"
    ends `uc-agent.exe` (restoring the desktop first if in gaming mode).
14. **Overlay.** In gaming mode press `Ctrl+Alt+O` → the overlay opens over
    Big Picture; press it again (or Esc / B) → it closes. In desktop mode
    the hotkey does nothing (log: `overlay is off outside gaming mode`)
    unless `[overlay] in_desktop_mode = true`. Leaving gaming mode with the
    overlay open closes it.

Report anything odd with the matching log lines.
