# WP-05 manual check: power hooks (about 5 minutes)

Download the `ultimate-console-<sha>` artifact from the CI run of the PR (or
build with `cargo build --release`), unzip it, and open PowerShell there.

```powershell
$env:UC_HOME = "$env:TEMP\uc-test"
```

Have the TV's IP at hand (Settings > Network on the TV). Below it is
`192.168.1.50`; use yours.

1. `.\uc-probe.exe power net --tv-ip 192.168.1.50` → your Ethernet/Wi-Fi
   adapter shows as `[up]` with its address (e.g. `192.168.1.20/24`), and the
   last line is `network ready: true`.
2. Start the watcher:
   `.\uc-probe.exe power watch --tv-ip 192.168.1.50 --hold-suspend-ms 5000`
   → `watching power events`, the network lines, then `power event
   event=display on` within a second.
3. Leave it idle until the screen turns off by itself (or set
   "Turn off the screen" to 1 minute) → `display dimmed` and/or
   `display off`; move the mouse → `display on`.
4. Sleep the PC (Start > Power > Sleep). Wait ~15 s, wake it with the
   keyboard/mouse. In the window you should see, in order:
   - `power event event=suspend`, then `network at suspend: …`;
   - `suspend handler alive: +100 ms …` lines. **Note the last one before
     the wall-clock jump**: that is how long Windows waited for the suspend
     handler. (Expect around 2000 ms; anything under 1500 ms is a problem for
     the TV sleep, tell Claude.)
   - after the wake: `resume (automatic)`, then `resume (user input)`;
   - `+N ms` adapter lines, then **`network ready N ms after resume`**. Note
     N: it is how long the agent will wait before waking the TV.
   - Any `repeated power event dropped` lines are fine (expected
     de-duplication).
5. Repeat step 4 once from Steam Big Picture's own power menu (Sleep), so we
   know it takes the same path. Note both numbers again.
6. Ctrl+C. The same output is in `%TEMP%\uc-test\data\logs\probe-power.<today>.log`;
   paste the two numbers (and the log if anything looked off) into the thread.

Clean up: `Remove-Item -Recurse "$env:TEMP\uc-test"`.
