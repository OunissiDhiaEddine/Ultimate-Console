# WP-09 manual check: settings app (about 5 minutes)

Download the `ultimate-console-<sha>` artifact from the CI run of the PR (or
build with `cargo build --release`), unzip it, and open PowerShell there.

The real agent (WP-08) isn't built yet, so most of this runs against the
built-in fake agent (`--mock`). Nothing in mock mode touches the PC: no
display, TV, Explorer or registry changes.

```powershell
$env:UC_HOME = "$env:TEMP\uc-test"
```

## Without an agent

1. `.\uc-settings.exe` → the window opens. The header says
   "Agent not reachable (the agent is not running)" with a **Start agent**
   button. Every settings page says to start the agent.
2. Press **Start agent** → the footer says "Starting the agent…". (The WP-00
   stub agent exits right away, so the header stays "not reachable". That's
   expected until WP-08.)
3. Close the window. `%TEMP%\uc-test\data\logs\settings.<today>.log` exists.

## With the mock agent

4. `.\uc-settings.exe --mock` → orange "MOCK AGENT" label, "Agent 0.1.0
   running · Mode: Desktop · TV: not set up".
5. **Hotkeys**: the three defaults show "OK". Press **Record** on the overlay
   row, then `Ctrl+Alt+G` → red "same shortcut as the gaming mode shortcut"
   and **Save** is greyed out. Record `Alt+F4` → "reserved by Windows".
   Record `Ctrl+Alt+K` → OK. Press **Reset** → back to `Ctrl+Alt+O`.
   Press Record then `Esc` → recording stops, shortcut unchanged.
   On your AZERTY/Arabic layout: record `Ctrl+Alt+E` and check the key you
   see is recorded (the real AltGr warning comes with the agent).
6. **Display**: two fake displays. Pick "#2 IRIS TV (HDMI)", open
   **Resolution** → 3840×2160 @ 60 Hz etc. Press **Save** → "Saved." in the
   footer.
7. Press **Enter gaming mode** in the header → mode goes "Entering…" then
   "Gaming"; the button becomes **Exit gaming mode**. **Panic restore** →
   "Desktop".
8. **TV**: press **Find TV** → "IRIS Android TV (192.168.1.50:5555)"; click
   it, press **Pair** → green "Paired … (MAC A0:B1:…)", IP and MAC filled in
   below, "Unsaved changes" in the footer. Save. Then **Wake** → "Wake: TV is
   on", and the header shows "TV: on". Type `zz` in TV MAC → red error and
   Save greyed out; **Revert** fixes it.
9. **Audio**: tick the switch box, pick "IRIS TV (NVIDIA …)", Save.
10. **About / Updates**: **Check now** → "Update token needed". Paste any text
    in the token box, **Save token** → "A token is saved."; **Check now** →
    "Up to date". **Open logs folder** opens Explorer on the logs folder.
    **Uninstall…** is greyed out in mock mode.
11. Resize the window small → pages scroll, nothing is cut off.

## Uninstall check (run after WP-10's installer exists)

12. After uninstalling from "Apps & features" (or the app's **Uninstall…**),
    run a saved copy of the exe without `UC_HOME`:
    `.\uc-settings.exe --check-uninstall | Write-Output` → every line says
    `gone` and the last line is "Everything is gone." (exit code 0).

Clean up: `Remove-Item -Recurse "$env:TEMP\uc-test"`.
