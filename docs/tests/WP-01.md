# WP-01 manual check: display switching (about 5 minutes)

Download the `ultimate-console-<sha>` artifact from the CI run of the PR (or
build with `cargo build --release`), unzip it, and open PowerShell there.
Have the TV plugged in and turned on. Keep a second way to see the desktop
handy: `switch` reverts on its own after 15 s unless you press Enter, and
`display-before-switch.json` is always written first, so
`.\uc-probe.exe display restore display-before-switch.json` brings the old
layout back (Win+P → "Extend" is the last resort).

1. `.\uc-probe.exe display list` → every connected screen with a number,
   name, connector (the TV should say `HDMI`), current mode, a device path
   starting with `\\?\DISPLAY#`, and `HDR` if the TV supports it.
   Note the TV's number (below: `2`).
2. `.\uc-probe.exe display identify` → a big number in the middle of each
   active screen for 3 s, matching the numbers from step 1.
3. `.\uc-probe.exe display snapshot --out before.json` → "saved N display(s)"
   plus one line per screen with resolution, refresh and position.
4. `.\uc-probe.exe display switch 2` → only the TV stays on, it is the
   primary display (taskbar/desktop icons move to it). Do **not** press
   Enter: after 15 s the old layout comes back (`reverted (Exact)`), with
   the same positions, resolutions and primary monitor as before.
5. `.\uc-probe.exe display switch 2 --revert-after 0`, then
   `.\uc-probe.exe display restore before.json` → `restored (Exact)` and the
   old layout is back.
6. Mode and HDR: `.\uc-probe.exe display switch 2 --width 1920 --height 1080 --refresh 60 --hdr`
   → TV at 1080p60 with HDR on (Settings → Display shows it). Let it revert;
   HDR on the TV goes back to how it was.
7. A mode the TV doesn't have, e.g. `--width 1234 --height 567`, still
   switches and prints `warning: 1234x567 ... is not offered`.
8. Wait for the TV: turn the TV off with its remote, run
   `.\uc-probe.exe display wait 2 --timeout 30`, then turn the TV on.
   Write down whether it returned at once (TV still reported while off) or
   only after the TV came on, and how long it took. This decides how the
   orchestrator sequences "wake TV → wait → switch".
9. Re-assert after sleep: `switch 2 --revert-after 0`, sleep the PC (S3),
   wake it, then run `.\uc-probe.exe display list`. Note whether the other
   monitors came back on by themselves. Run `switch 2 --revert-after 0`
   again (it must work and be quick), then `display restore before.json`.

Report: the output of step 1, the outcome words from steps 4/5 (`Exact`,
`Database` or `Extend`), and the notes from steps 8 and 9.
