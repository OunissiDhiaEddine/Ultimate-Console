# WP-07 · Overlay — manual checklist (about 5–10 minutes)

Run on the real PC from a normal (non-admin) terminal, with `uc-probe.exe`
from the CI artifact or `cargo build --release`. Have two or three normal
windows open (Notepad, a browser, File Explorer) and, for step 6, a game.
Plug in an Xbox-compatible controller for step 4.

The probe registers the overlay hotkey itself (default `Ctrl+Alt+O`), the
same way the agent does. If the agent is running it already owns that
hotkey: quit the agent first or pass `--hotkey "Ctrl+Alt+P"`.

1. **Opens and looks right**
   `uc-probe overlay --fake`
   - [ ] A dimmed backdrop fades in over the monitor with a centred card and
         three panels: Tasks, Volume, Info.
   - [ ] Text is sharp (not blurry) on a scaled display (125 % / 150 %) and on
         the TV at 4K.
   - [ ] The Tasks panel shows one tile per open window, each with a **live
         thumbnail** (play a video in the browser: its tile moves). Tiles with
         no thumbnail show the exe name instead. **If no thumbnail appears on
         any tile, report it: that means DWM draws thumbnails under the
         DirectComposition content on this build of Windows.**
   - [ ] The window that was in front before opening is selected first.
   - [ ] The footer shows `CPU 23%  GPU 61%  RAM 9.0 GB / 32.0 GB` (fake numbers).
   - [ ] `Ctrl+Alt+O` again fades it out; `Ctrl+Alt+O` again brings it back.

2. **Keyboard**
   - [ ] Arrows move the selection; Enter switches to that window and the
         overlay closes.
   - [ ] Tab / Shift+Tab (and 1, 2, 3) change panels; Esc closes the overlay
         and focus goes back to the window that had it.
   - [ ] Delete closes the selected window (Notepad with unsaved text asks to
         save, that's expected); the tile disappears within a second.
   - [ ] Shift+Delete shows "End this process?"; Esc cancels; Shift+Delete then
         Enter ends it (try on a throwaway Notepad).
   - [ ] Clicking a tile switches to it; clicking outside the card closes.
   - [ ] Clicking another window while the overlay is open closes it.

3. **Real volume and stats** (quit the fake run with Ctrl+C)
   `uc-probe overlay`
   - [ ] Volume panel: "Master volume" matches the Windows volume flyout;
         Left/Right changes it in 5 % steps (watch the flyout / tray icon);
         Enter mutes and unmutes.
   - [ ] With music playing in a browser, the browser appears as an app row;
         select the browser on the Tasks panel first and its row is listed
         right under Master with "(selected task)". Left/Right changes only
         that app (check in Volume mixer).
   - [ ] `+` / `-` and M change master volume / mute from any panel.
   - [ ] Info panel: the selected task's CPU / GPU / RAM / uptime appear after
         about a second and update once per second; Left/Right walks tasks.
   - [ ] Footer system line roughly matches Task Manager.

4. **Controller**
   - [ ] D-pad and left stick move, A switches, B closes, LB/RB change
         panels, X closes the window, Y asks to end the process (B cancels).
   - [ ] Holding a direction repeats; LT/RT change master volume.
   - [ ] Map a Steam Input chord (e.g. Guide+Y) to `Ctrl+Alt+O` in Steam:
         opening the overlay with it does **not** trigger "end process"
         (buttons held while opening are ignored until released).
   - [ ] Note whether Steam Big Picture also reacts to the controller while
         the overlay is open (it shouldn't when BP isn't in front; report if
         it does).

5. **Idle cost**
   `uc-probe overlay --hidden` and leave it closed for a minute.
   - [ ] Task Manager: `uc-probe.exe` at 0 % CPU and 0 % GPU while closed.
   - [ ] While open: low single-digit CPU, and the process's "Dedicated GPU
         memory" drops back after closing.

6. **Over a game**
   Start a game in **borderless / windowed fullscreen**, press `Ctrl+Alt+O`.
   - [ ] The overlay appears over the game; the game's tile is selected.
   - [ ] A switches back into the game and it has keyboard/controller focus.
   - [ ] (Optional) In **exclusive fullscreen**, the game may minimise when
         the overlay opens. That's the known limitation from plan §2.9;
         note what happens.

7. **Multiple monitors**
   - [ ] With the foreground window on the second monitor (or the TV), the
         overlay opens on that monitor at its resolution.

8. **Volume keys and the volume popup**
   `uc-probe overlay --hidden --volume-keys` (takes the volume keys from
   Explorer while it runs; Ctrl+C gives them back).
   - [ ] Volume up / down on the headset (or keyboard) changes the volume in
         2 % steps and a small card fades in at the bottom centre of the
         monitor with a speaker icon, a bar and the percentage.
   - [ ] Holding the button keeps changing it; the card fades out about two
         seconds after the last press.
   - [ ] Mute shows "Muted" with a grey bar; volume up or down unmutes.
   - [ ] The card never takes focus: type in Notepad while pressing volume
         keys, the text keeps going into Notepad.
   - [ ] With the overlay open (`Ctrl+Alt+O`), volume keys move its master
         slider instead and no card appears.
   - [ ] In real gaming mode (agent, `Ctrl+Alt+G`) the same works over Big
         Picture; back on the desktop the normal Windows flyout is back.

Logs: the probe prints them and writes `probe-overlay.*.log` in the logs
folder (`uc-probe paths`).
