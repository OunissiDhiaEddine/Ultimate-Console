# WP-04 manual check: audio (about 5 minutes)

Download the `ultimate-console-<sha>` artifact from the CI run of the PR (or
build with `cargo build --release`), unzip it, and open PowerShell there.
Nothing here needs admin rights. Have the TV (or any second output, such as
headphones) connected so there are at least two output devices.

1. `.\uc-probe.exe audio list` → every active output device with its name and
   id; the current default has a `*`. The names match the Sound settings page.
   Copy the id of the device that is **not** the default (the TV's HDMI one).
2. `.\uc-probe.exe audio set-default "<id>"` → prints the new default. The
   Windows volume flyout and Settings → System → Sound now show that device,
   and sound plays on it.
3. Set it back: `.\uc-probe.exe audio set-default "<original id>"`.
   `.\uc-probe.exe audio set-default "nope"` → `error: audio output device not found or not active`.
4. `.\uc-probe.exe audio volume` → the same percentage as the volume flyout.
   `.\uc-probe.exe audio volume 40` → the flyout shows 40.
5. `.\uc-probe.exe audio mute toggle` → the flyout shows muted; run it again
   → unmuted. `.\uc-probe.exe audio mute` → `mute off`.
6. Play something (a YouTube video in a browser, or a game). Then
   `.\uc-probe.exe audio apps` → a line for it with its PID and exe name
   (e.g. `msedge.exe`), plus `System Sounds` with PID 0.
7. `.\uc-probe.exe audio app-volume <pid> 20` → that app gets quieter and the
   Volume mixer (right-click the speaker icon → Volume mixer) shows 20 for it;
   other apps are unchanged. `.\uc-probe.exe audio app-mute <pid> toggle` →
   that app goes silent; toggle again to restore. Set it back to 100.
8. `.\uc-probe.exe audio app-volume 4 50` (a PID with no sound) →
   `error: process 4 has no audio session on the default output device`.

Report anything that differs, especially if step 2 fails (that uses the
undocumented `IPolicyConfig` interface) or if a game's PID in step 6 differs
from the PID of its window (the overlay will need to match child processes).
