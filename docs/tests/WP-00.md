# WP-00 manual check (about 5 minutes)

Download the `ultimate-console-<sha>` artifact from the CI run of the PR (or
build with `cargo build --release`), unzip it, and open PowerShell there.

Use a scratch folder so nothing real is touched:

```powershell
$env:UC_HOME = "$env:TEMP\uc-test"
```

1. `.\uc-probe.exe paths` → four paths, all under `%TEMP%\uc-test`.
2. `.\uc-probe.exe config default` → a TOML config with the three default
   hotkeys `Ctrl+Alt+G`, `Ctrl+Alt+O`, `Ctrl+Alt+Shift+R`.
3. `.\uc-probe.exe config validate` → `config OK`.
4. `.\uc-probe.exe hotkey "Ctrl+Alt+G"` → no errors; the AltGr note shows.
   `.\uc-probe.exe hotkey "Alt+F4"` → `error: reserved by Windows`.
5. `.\uc-agent.exe` → returns right away (stub). Then check that
   `%TEMP%\uc-test\data\logs\agent.<today>.log` exists and contains
   `uc-agent starting (stub)`.
6. `.\uc-probe.exe state show` → `"mode": "desktop"`.
7. Without `UC_HOME` (`Remove-Item Env:UC_HOME`), `.\uc-probe.exe paths`
   → config under `%APPDATA%\UltimateConsole`, the rest under
   `%LOCALAPPDATA%\UltimateConsole`.

Clean up: `Remove-Item -Recurse "$env:TEMP\uc-test"`.
