# WP-10 manual check (about 10 minutes)

Needs a published release (or the `ultimate-console-<version>` artifact of a
dry-run Release workflow, which holds the same `Releases\` folder).
Do it from desktop mode.

**Install**

1. Run `UltimateConsole-win-Setup.exe`. No UAC prompt. If SmartScreen
   warns: *More info → Run anyway*.
2. The settings app opens. Task Manager → Details shows `uc-agent.exe`
   running from `%LOCALAPPDATA%\UltimateConsole\current\`.
3. Start menu has **Ultimate Console**, with the controller icon; it opens
   the settings app. *Settings → Apps → Installed apps* lists it.
4. In PowerShell: `& "$env:LOCALAPPDATA\UltimateConsole\current\uc-probe.exe" update autostart`
   → prints the Run value with the quoted `current\uc-agent.exe` path.
   Sign out and back in: the agent is running again.

**Updates** (no token: the repo is public)

5. The settings *About / Updates* page has no token box.
6. `uc-probe update check` → `up to date` (or the newer version if there is
   one).
7. Updating (once a second release exists): *Check now* → "update
   available". Enter and leave gaming mode → within a minute the agent
   restarts on the new version (About page), no settings window pops up,
   and nothing happened while in gaming mode.

**Uninstall**

8. Enter gaming mode, Ctrl+Alt+Shift+R back out, then uninstall from
   *Installed apps* (or the settings *Uninstall* button).
9. The agent is gone from Task Manager, the taskbar is normal.
10. Check that nothing is left:
    - `%APPDATA%\UltimateConsole` and `%LOCALAPPDATA%\UltimateConsole` don't exist
      (Velopack may leave an empty folder for a few seconds).
    - `reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Run /v UltimateConsole` → not found.
    - `reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\UltimateConsole` → not found.
    - The Start-menu entry is gone.
