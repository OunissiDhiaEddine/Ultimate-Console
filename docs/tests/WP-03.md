# WP-03 manual check (about 5 minutes)

Download the `ultimate-console-<sha>` artifact from the CI run of the PR (or
build with `cargo build --release`), unzip it, and open PowerShell there.
Steam must be installed and signed in. Save your work first: steps 2 and 3
hide the taskbar.

**Escape hatch at any point:** Ctrl+Shift+Esc → File → Run new task →
`explorer`.

1. `.\uc-probe.exe shell status` → `shell (taskbar) running: true`, at least
   one explorer.exe pid, the right `steam.exe` path.
2. **Spike.** `.\uc-probe.exe shell kill-explorer --watch-secs 30 --restore`
   → taskbar and desktop icons vanish without signing out, the probe prints
   `RESULT: no taskbar after 30 s`, then the taskbar comes back. Fill in the
   table in `docs/spikes/shell.md` with the `RESULT:` line and your `winver`.
3. Open a File Explorer window, then
   `.\uc-probe.exe shell kill-explorer --watch-secs 10` → the window closes
   too (it may be listed under `terminated`). Then
   `.\uc-probe.exe shell start-explorer` → `started explorer.exe … taskbar
   up: true`, and the taskbar is not "elevated" (right-click Start works as
   usual). Running it again prints `Explorer was already running`.
4. With Steam closed: `.\uc-probe.exe shell bp-launch` → `StartedSteam`,
   Big Picture opens, `Big Picture up after …`.
5. `.\uc-probe.exe shell bp-find` → a `MATCH:` line. If it says `none`,
   copy the candidate lines into the PR: the class/title need adjusting
   (e.g. a non-English Steam has a translated title; set
   `[steam] bp_window_title` in the config).
6. In a second PowerShell: `.\uc-probe.exe shell bp-watch` → `APPEARED`
   right away. In Big Picture, go to Power → Exit Big Picture → about 2 s
   later `CLOSED`.
7. With Steam still running in desktop mode: `.\uc-probe.exe shell bp-launch`
   → `OpenedInRunningSteam`, the watcher prints `APPEARED`. Then
   `.\uc-probe.exe shell bp-close` → Big Picture closes, `CLOSED`.
8. Optional: with the watcher running and Big Picture open, quit Steam
   entirely (Power → Exit Steam) → `CLOSED`.

Stop the watcher with Ctrl+C.

## Steam in the tray (0.1.2)

9. Close the Steam window with the X so Steam only sits in the tray, then
   `.\uc-probe.exe shell bp-launch` → Big Picture opens, `Big Picture up
   after …`. If it needed a retry, the log says `asking Steam again`. If it
   still fails, the log lists Steam's windows (`Big Picture never showed
   up`); paste that line into an issue.
